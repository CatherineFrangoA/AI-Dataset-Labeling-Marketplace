# Problem Statement

## 1. Title
AI Dataset Labeling Marketplace

## 2. Domain
Artificial Intelligence / Machine Learning

## 3. Who is the User?
- Admin
- Dataset Owner
- Labeler

## 4. What Problem Are We Solving?
Machine learning models require high-quality labeled datasets for training. Many organizations struggle to manage dataset labeling efficiently. This application provides a centralized platform where dataset owners can upload datasets, assign labeling tasks, review completed work, and download labeled datasets.

## 5. Proposed Solution
The application allows dataset owners to upload datasets, assign labeling tasks to labelers, review completed labels, and download the final labeled dataset. Admin manages users and monitors the overall system.

## 6. Core Entities / Database Tables
- Users
- Datasets
- LabelTasks
- Labels
- Categories
- Reviews
- Notifications

## 7. User Roles & Permissions
- Admin
- Dataset Owner
- Labeler

## 8. Success Criteria
Users should be able to upload datasets, complete labeling tasks, review labels, and download labeled datasets successfully.

## 9. Out of Scope
- Payment Gateway
- Mobile Application
- Live Chat
- Multi-language Support

## 10. Chosen Track
Python (FastAPI) + React + MySQL
